# Подводная лодка «Жемчужина»

Учебный проект, стихия — вода. Лодка перевозит пассажира под водой с помощью гребного винта.

![Подводная лодка «Жемчужина»](submarine.png)

Автор ТЗ и тестов: Синицина Полина Владимировна. 
Ревьюеры: Харченко Владислав Андреевич и Хвальчев Сергей Павлович. 
Разработчик: Новожилов Евгений Игоревич

- `SPEC.md` — техническое задание.
- `TEST_CASES.md` — тест-план.
- `tests/` — тесты автора и обёртка пилота.
- `reviews/` — шаблоны для ревьюеров.
- `RESPONSES.md` — ответы автора на замечания.
- `CHANGELOG.md` — журнал изменений.

Запуск из корня репозитория: `python3 -m unittest discover -s tests -v` (Python 3.9+).
