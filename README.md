# Подводная лодка «Жемчужина»

Учебный проект, стихия — вода. Лодка перевозит пассажира под водой с помощью гребного винта.

Автор ТЗ и тестов: Синицина Полина Владимировна. Ревьюеры: Харченко и Хвальчев. Разработчик: назначается отдельно.

- `SPEC.md` — техническое задание.
- `TEST_CASES.md` — тест-план.
- `tests/` — тесты автора и обёртка пилота.
- `reviews/` — шаблоны для ревьюеров.
- `RESPONSES.md` — ответы автора на замечания.
- `CHANGELOG.md` — журнал изменений.

Запуск из корня репозитория: `python3 -m unittest discover -s tests -v` (Python 3.9+). На этапе автора реализация `submarine.py` ещё отсутствует, поэтому запуск завершится ошибкой импорта. После ревью разработчик создаёт этот модуль по ТЗ; тесты автора он не изменяет. Укажи ссылку на GitHub в `SPEC.md` после создания репозитория.
